## 本次补齐与修复

此前项目已包含基础 SwiftUI 窗口、30 篇文章及配图。本次补齐可点击面包屑、跨页面的返回与前进、全局搜索入口与自动焦点；改进搜索和历史的整行按钮及辅助功能入口，浏览历史按最近访问排序。

加载器兼容可选关键词、提供空内容与重复 ID 的明确错误。搜索只匹配可见文字。首页年份避免自动插入千位分隔符。文章附加可离线显示的阅读线索，正文长度统一达到 PRD 范围。

打包脚本默认使用 Release，先在临时目录组装并校验，再替换输出 App；丢失资源时直接失败。资源仅复制一次，移除此前的重复资源 bundle。本地签名可供本机运行，未进行 Developer ID 签名和 Apple 公证。交付是本机构建的 arm64 App。

## 内容校核记录

书目文字作为进一步阅读线索，不表示每一句叙述已经经过专业审校。PRD 已将大规模史料研究和专业审校排除在此次工期之外。

- 陈桥兵变文章：区分建隆年间的开局与此后十余年的南方统一过程，避免将南唐灭亡误置于建隆年间。参考[《宋史》太祖本纪](https://zh.wikisource.org/wiki/宋史/卷001)。
- 澶渊之盟：对照景德元年亲征与订盟记载，保留宋历景德元年岁末、公历 1005 年的说明。参考[《宋史》真宗本纪二](https://zh.wikisource.org/wiki/宋史/卷007)。
- 杯酒释兵权：明确宴饮叙述来自传世材料；补充通常采用的建隆二年与《宋史》乾德初年的纪年差异。参考[《宋史》石守信传](https://zh.wikisource.org/wiki/宋史/卷250)。
- 绍兴和议：银、绢补齐「两」「匹」单位；区分绍兴十一年岁末与公历 1142 年的岳飞遇害时间。参考[《宋史》高宗本纪六](https://zh.wikisource.org/wiki/宋史/卷029)。
- 采石之战：修正「金军一处江面失守」的主语错误，明确采石阻击与其他渡口防御的共同作用。参考[《宋史》虞允文传](https://zh.wikisource.org/wiki/宋史/卷383)。
- 崖山海战：核对宋末海上朝廷、赵昺与陆秀夫的主要线索，保留死亡人数不应作精确统计的提示。参考[《宋史》二王本纪](https://zh.wikisource.org/wiki/宋史/卷047)。
- 活字印刷：核对庆历年间、毕昇及胶泥字印的记载。参考[《梦溪笔谈》技艺](https://zh.wikisource.org/wiki/夢溪筆談/卷18)。

## 自动验证

执行 `Scripts/check-mvp.sh`：先测试源码内容，再构建 App，然后对 App 内的实际 Content 再运行同一测试集。两轮各 16 项测试。

覆盖节点数量与类型、指定年份、正文长度、正文配图数、图片解码和比例、封面差异、知识死链、关联入口、离线 HTML、阅读线索、标题与正文搜索、时间轴排序、浏览导航、重复访问面包屑、新节点扩展、可选字段与重复 ID 错误。

手工实际窗口验证了首页、正文配图、内部链接、关联卡片、首篇返回首页、前进恢复、面包屑返回、⌘F 焦点、搜索结果按钮、浏览历史重开、时间轴及其末端事件。独立副本启动没有改变系统联网设置；离线能力依据静态资源自包含、无服务器/API 依赖及本地资源加载验证。
